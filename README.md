# Mırnav

Odaklanma seanslarını tamamlayarak sanal bir sokak kedisi kolonisi büyüttüğün, reklamsız bir mobil uygulama.

## Geliştirme

```bash
npm install
npx expo start
```

Komutlar:

- `npm run lint` — ESLint
- `npm run format` — Prettier
- `npm run android` / `npm run ios` / `npm run web`

## Teknoloji

React Native + Expo (managed), TypeScript, Expo Router, Zustand, MMKV, i18next (tr/en).
